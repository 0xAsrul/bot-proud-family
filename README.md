# A Family Scene That Makes the Judge Proud

A small, warm and funny domestic moment at the kitchen table: Dad fixes the wobble, the wobble wins, and a six-year-old delivers the verdict.

## Run it

```sh
python3 main.py
```

This writes the scene to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when running locally).
